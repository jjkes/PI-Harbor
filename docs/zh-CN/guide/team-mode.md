# 协同模式

协同模式将一段本地 Desktop 对话变成团队。主 agent（L0）会把你的请求拆成有界任务，
委派给你开启的成员，并检查他们的报告。只允许再增加一层严格受限的委派：L1 成员可以
启动 L2 成员，L2 永远不会获得委派工具。

Remote 和 Native Pi 对话不能启用本地协同名册，远程项目草稿也不提供「团队」。关闭协同
模式时，会话保持原来的单层行为。

## 开启团队

打开 Composer 下方的模式菜单，也就是显示 Agent、Plan 或 Goal 的芯片，然后选择
「团队」。可配置的 `toggleTeamMode` 快捷键（默认 Ctrl/Cmd+Shift+T）执行相同操作。
团队可与三种模式中的任意一种组合，开启时芯片会显示一个小的「团队」徽标。

在本地草稿中选择「团队」会立即创建会话，无需先发送消息。Composer dock 会打开
**Subagent** 页。如果未发送消息就离开，空会话仍会留在侧边栏中。

首次在对话中开启团队时，设置中所有已启用的子代理角色都会开启。关闭团队会保留成员及
其设置，供下次开启时使用。

## 选择成员

dock 的 Subagent 页中，「成员 n/m」显示本会话已开启成员数／设置中已启用角色数。
弹层列出「设置 → 子智能体」中定义的全部角色，设置中已停用的角色排在末尾。点击一行
即可切换该成员在本对话中的开关。「全部开启」和「全部关闭」会修改所有符合条件的行；
「全部开启」会跳过设置中已停用的角色。

角色在设置中创建、编辑和删除，而不是在弹层中操作。在设置中停用的角色仍会列出，但
显示为暗淡状态且开关禁用。稍后创建的角色在现有团队对话中默认关闭。「在设置中管理
角色」会打开「设置 → 子智能体」。

## 为本对话配置成员

点击行内铅笔可打开成员面板。「角色设定」按设置中的定义展示角色：描述、指令、模型、
推理强度、可用工具，以及内置角色的权限作用域。「在设置中编辑角色」会打开
「设置 → 子智能体」。

「本会话临时配置」只更改此对话中的成员：

- **模型：**选择「跟随角色」，或选择 provider/model。选定模型还会清除角色的备用模型，
  主 agent 无法覆盖它。
- **推理强度：**选择「跟随角色」，或选择一个级别。该级别仍受模型支持范围的上限限制。
- **可用工具：**选择「跟随角色」，或自定义一组工具，也可以选择包含「继承主会话工具」。
  授予写入工具会使成员在这段对话中可写，成员面板会明确提示这一点。

修改过的字段会标记为「已修改」，「恢复角色默认」会清除这些修改。这些设置绝不会改变角色
或其他对话，成员关闭时也会保留它们。成员及其设置的更改会立即保存，并从下一条消息开始
生效；它们不会停止已经在运行的成员。按 Escape 关闭面板后，焦点返回「成员」按钮。

已关闭、在设置中停用、无法解析或超出 provider 预算的成员无法被调用。没有成员开启时，
主 agent 会独立工作。

## 主 agent 如何与团队协作

团队开启时，主 agent 默认进行委派。它只直接处理需要向你提问、撰写任务简报所需的查询、
整合报告、最终验证，以及撰写简报的成本超过改动本身的工作。它只调用已开启的成员，为每个
成员提供自包含的任务简报，不互相等待地启动独立任务，并由自己或另一名成员检查每份报告，
因为成员绝不会验收自己的输出。Task 列表中每个成员都会标注访问级别——只读、能运行命令并可
借此改动文件、或写文件——主 agent 按该级别而不是按角色名匹配任务。成员会遵守请求范围，并把
需要你决定的事项交回主 agent。团队开启时，主 agent 无法使用其他生成 agent 的工具，例如
Session Orchestrator 的 `SessionTask`。

在 Plan 或 Goal 模式下 Task 工具不可用，因此主 agent 会自己做只读调查，并提交该模式要求的
计划或目标；你批准后即可恢复委派。

## 查看并控制执行

对话区中的每次 Task 扇出只有一行摘要，显示聚合状态、数量和耗时。点击摘要会在
Composer dock 中打开 Subagent 页；其停止控件保持独立。

dock 用一棵实时树覆盖已加载会话，而不是按回合分别成图。树按 Main → L1 → L2 展示，
L2 位于调用它的 L1 右侧。每个节点显示模型、状态、耗时和步骤数。点击节点会打开或激活
对应的子代理工作面板标签。运行中节点的「Stop」会取消该节点的整棵子树，工具栏另有
「停止全部子代理」。这棵树没有按回合分页、方向键节点导航、token 用量或 L1 子树折叠。

dock 容器宽度低于 520px 时，Main 移到树上方，L2 仍在 L1 右侧；需要时可横向滚动面板。
已加载转录范围之外的委派要等相应行加载后才会出现。Remote 会话的已加载 Task 行存在且
可归因时，也能使用同一个 Subagent 页，但不会获得本地协同名册或本地 Todo 和后台任务侧。

L1 会等自己的子节点交回报告后，才把结果交给 L0。重启后，树和成员设置会从持久化的转录
与会话配置重建。

为限制权限和成本：

- 最多两层委派，且不受模型指令影响；
- 每个 L1 单次运行最多启动 4 个子节点；
- 现有的每会话 10 个运行中委派上限统计所有深度；
- 只读 L1 只能启动只读成员。
